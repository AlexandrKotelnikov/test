# Limitations

- Most experiments use compact synthetic implementation tasks.
- Repetitions per condition are small.
- Worker-defined step boundaries can affect route granularity.
- Frozen evaluators provide a known oracle rather than fully unknown production acceptance.
- On-disk audit size is not a measure of hidden reasoning cost or wall-clock compute.
- The Project Atlas file in this repository is a curated portfolio edition based on the original skill plus documented consistency fixes; it is not claimed to be the exact local file used in every historical run.
- Results are behavioral observations for specific tasks, not universal claims about all models or agent environments.
