# Roadmap

## Next experiments

- Hidden dependency route choice without explicit evidence-damage hints.
- Conflicting evidence where two verifiers disagree.
- Multi-agent concurrent edits and stale coordinate reconciliation.
- Larger real-world repository tasks with external hidden acceptance.
- Measurement of token cost, elapsed time, and state overhead.

## Productization questions

- Standard schema for frozen obligation registries.
- Lightweight adapters for different agent environments.
- Visual route rendering generated from text state, without making a GUI mandatory.
- Public benchmark release with reproducible runner scripts.
