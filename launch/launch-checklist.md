# v0.2.0 public launch checklist

## Product readiness

- [ ] Live simulator opens in a private browser window.
- [ ] All four scenarios load.
- [ ] Each scenario has at least one direct route to `LANDING`.
- [ ] `Copy Atlas prompt` works or falls back to a visible prompt dialog.
- [ ] Repository validation is green on Python 3.9 and 3.12.
- [ ] Pages deployment is green.

## Repository presentation

- [ ] Repository description is concise and benefit-led.
- [ ] Topics include `llm-agents`, `agent-skills`, `ai-evaluation`, `codex`, and `reproducible-research`.
- [ ] Social preview is uploaded in repository settings.
- [ ] Repository is pinned first on the GitHub profile.
- [ ] README buttons open the live demo, install index, skills, and evidence.
- [ ] `v0.2.0` release is created from `launch/release-notes-v0.2.0.md`.

## Evidence integrity

- [ ] No universal superiority claim appears in launch copy.
- [ ] Parity and `MEASUREMENT_INVALID` results remain visible.
- [ ] Simulator is described as educational and deterministic.
- [ ] Installation guides distinguish documented patterns from verified harness runs.

## Launch sequence

- [ ] Publish Russian LinkedIn post with one simulator screenshot.
- [ ] Reply to substantive comments during the first day.
- [ ] Publish English LinkedIn post on a different day.
- [ ] Publish one community-specific Reddit discussion, not a mass cross-post.
- [ ] Publish the Habr article after collecting first questions.
- [ ] Submit to Hacker News only when the public demo works without authentication.

## Measurement

Record at launch, +24 hours, +7 days, and +30 days:

- unique GitHub visitors;
- clones;
- stars and forks;
- live-demo visits if available;
- external referrers;
- installation questions;
- independent reproductions;
- concrete agent failure cases submitted.

## Next research gate

Do not start the Hidden Consequences benchmark merely because launch activity slows. Start it when the design, frozen evaluator, and registered conclusions are ready, or when an external failure case materially improves the test.
