## Positioning

Lead with the problem and the falsifiable research result, not with the framework name:

> Long-running AI agents can produce a lot of work without moving toward what the user will accept. We built two portable navigation skills, tested them against a strong planner, and published the wins, ties, and evaluator failures.

## Core claims that are supported

- Atlas provides an explicit Delivery–Evidence–Alignment state and route model.
- Astrolabe and Atlas are portable text-only skills.
- Atlas removed one cross-track step in both Evidence-deficit repetitions.
- Strong Planner baselines tied the navigation skills in several scenarios.
- One experiment was rejected as `MEASUREMENT_INVALID` after evaluator defects were found.
- The repository includes an interactive educational simulator and complete reports.

## Claims to avoid

- “Atlas is proven better than planning.”
- “The benchmark proves universal agent alignment.”
- “The simulator predicts real model performance.”
- “The skills guarantee correctness.”
