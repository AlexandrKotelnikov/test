# Project Atlas Simulator

A zero-dependency interactive demonstration of the coordinate navigation model in Project Atlas.

## Run locally

Open `index.html` directly in a modern browser. No build step, package manager, server, network connection, or external asset is required.

## Included scenarios

1. **Evidence deficit** — the product exists, but proof is missing or stale.
2. **Alignment breach** — functionality improved by violating a hard constraint.
3. **Orbit trap** — repeated optional work does not close required obligations.
4. **Route choice** — two compliant repairs create different Evidence damage.

Each maneuver updates:

- Delivery, Evidence, and Alignment;
- weighted distance to the accepted result;
- path length, net progress, and orbit ratio;
- obligation status;
- movement class;
- landing gates;
- the observable trajectory.

## Scope

This is an educational simulator, not an autonomous evaluator. Its deterministic scenario rules demonstrate the semantics of the skill; they do not claim to predict all agent behavior.
