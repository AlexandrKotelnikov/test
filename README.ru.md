# LLM Navigation Lab

**Текстовые навигационные навыки и воспроизводимые тесты для удержания сложных AI-агентов в направлении принятой пользователем цели.**

## Идея

Агент может активно менять файлы, исследовать, рефакторить и писать отчёты, но
при этом не приближаться к требуемому результату. Репозиторий исследует способы
отличить реальное движение к приёмке от деятельности, которая только выглядит
полезной.

## Навыки

- [Astrolabe / Orbit Trap v0.3](skills/astrolabe/) — обязательства, доказательства,
  proxy progress, orbit и correction maneuver.
- [Project Atlas v0.1.1](skills/project-atlas/) — координаты Delivery, Evidence и
  Alignment, курс, длина маршрута, cross-track и orbit ratio.

## Главный результат

Универсальное преимущество нового skill не доказано. Сильный Planner уже
покрывает многие навигационные механизмы. При этом Atlas в одном matched-состоянии
дважды избежал лишнего cross-track шага, а Astrolabe в одном сложном тесте дважды
быстрее начал восстановление.

Отрицательные и невалидные результаты сохранены — это часть методологии, а не
ошибка портфолио.

## Структура

- `skills/` — готовые переносимые skills;
- `experiments/reports/` — полные отчёты;
- `benchmarks/reproduction/` — замороженные пакеты тестов;
- `docs/` — методология, хронология, ограничения и кейс для портфолио;
- `assets/` — визуализации.
